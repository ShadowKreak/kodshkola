# Этап 3–4: программа курса и продолжение обучения

## Что изменено

- Добавлена таблица `lesson_visits` с внешними ключами и составным первичным ключом `(student_id, course_id)`.
- При открытии урока сохраняется последний просмотренный урок студента в рамках курса.
- В бизнес-логике добавлен `course_next_lesson`: сначала предлагает последний просмотренный незавершённый урок, иначе первый незавершённый урок по порядку разделов и уроков.
- Сводка студента теперь содержит `next_lesson` для каждого курса.
- В кабинете студента, списке курсов и на странице курса добавлены рабочие ссылки «Продолжить обучение».
- Старые данные и таблицы не удаляются. `CREATE TABLE IF NOT EXISTS` обеспечивает создание новой таблицы при следующем запуске приложения.

## Проверки

- Проверить синтаксис Python: `python -m compileall -q edu run.py seed.py`.
- Проверить запуск и сценарии: `pip install -r requirements.txt`, затем `python -m pytest -q`.
- Проверить вручную: открыть урок курса, перейти в кабинет, нажать «Продолжить обучение»; отметить урок завершённым и убедиться, что ссылка ведёт на следующий незавершённый урок.

## Ограничения

Полный набор Flask-тестов зависит от установки зависимостей в локальном окружении. В этой среде тесты могут быть недоступны, если Flask не установлен.
